# 因子体检 + 因子组合（RL 挖掘因子）

> 对 RL 挖掘出的正交价量因子做系统体检（可复现 / 过时 / 过拟合 / 鲁棒性），再用最优权重组合，把弱因子叠成更强的 alpha。

## 简历一句话（可直接用）

> 基于 RL（PPO + 分批正交贪心）挖掘 85 个正交价量因子，通过「可复现性 / 时间衰减 / 鲁棒性」三关体检确认有效性，再用线性最优权重 `w ∝ C⁻¹ρ` 组合，将验证期 RankIC 从单因子 0.017 提升至 **0.046**；并证明"少而精的正交因子适合线性组合，系统性的 alpha158 才适合非线性模型"。

## 核心成果

### 体检三关（`因子体检结果.md` §1–4）

| 关卡 | 方法 | 结论 |
|---|---|---|
| 可复现性 | StackVM 重放公式 | 85 因子全可执行，完整样本 IC 复现 |
| 时间衰减 | 逐年 IC（mine 2016-21 vs val 2022-26） | 不过时、不过拟合 |
| 鲁棒性 | 特征加噪声 + 窗口参数扰动 | 无崩溃，强因子极稳 |

### 组合实验（§5–6）

| 组合方式 | 验证期 IC |
|---|---|
| 单因子均值 | 0.017 |
| 等权 | 0.032 |
| 最优 C⁻¹ρ(带符号) | 0.042 |
| **剔除负 IC + 最优权重** | **0.046** |
| LightGBM(横截面 z 标签) | 0.022 |

### 一个有辨识度的结论（§7）

线性组合用"一阶信息"(单因子 IC)，LightGBM 用"高阶信息"(因子交互)：

- **我们的因子**：一阶强(78% 正 IC)、高阶弱(随机公式)→ 线性组合就是终点；
- **alpha158**：一阶弱(42% 正 IC)、高阶强(29 算子 × 5 窗口的系统结构)→ 靠 LightGBM 榨出交互 alpha。
